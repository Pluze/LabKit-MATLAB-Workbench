Use this section when changing the repository or operating its delivery workflows. App users should start with [Start](../start/README.md) or the [App catalog](../apps/README.md).

## Choose A Task

| Goal | Start here |
| --- | --- |
| Plan and run evidence for a source change | [Testing](testing.md) |
| Author or render reader documentation | [Documentation](documentation.md) |
| Maintain Apps outside the public repository | [Private Apps](private-apps.md) |
| Prepare versions, notes, tags, and assets | [Release](release.md) |
| Run codecheck, packaging, profiling, or documentation tools | [Maintainer tools](tools/README.md) |

Every task page states its owning source, required evidence, and boundaries. Delivery state belongs in pull requests and CI rather than reader manuals or Change records.
